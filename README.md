NookXeno is an Intelligent Real-time Data Processing Engine, leveraging High-Performance architecture for Auto-scaling analytics on a robust Platform.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/NookXeno.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

NookXeno is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
